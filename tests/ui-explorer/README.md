# UI Explorer and stable accessible selectors

Open **UI Explorer** from Studio's Design toolbar or bottom panel. Desktop selector fields also offer **Open in UI Explorer**. Choose an application window, select **MSAA** (Chromium/Electron/legacy applications) or **UI Automation** (Windows controls), and click **Inspect**. Inspection does not edit workflows, save files, or execute target controls.

Expand the hierarchy or search by accessible name, control type, AutomationId or class. Select an element to view its properties and generated selector. **Validate** resolves the selector using the same engine as Click/Get Text; **Highlight** outlines the resolved element without clicking it. **Copy selector** copies it. **Use in selected activity** edits only the selected activity's local selector in memory; a shared binding must be edited through the UI Target Library. **Save to UI Target Library** opens a draft and requires an explicit save.

MSAA selectors support `nameMatch: "IgnoreUnreadCount"` and `"Exact"` in their base64 JSON descriptor. Legacy descriptors without a mode use `IgnoreUnreadCount`. This only strips a trailing English numeric unread badge (`Esra 1 unread message`, `Esra 12 unread messages` → `Esra`). It does not match arbitrary prefixes, change roles or choose the first match. Two matching controls fail as ambiguous; choose Exact or a stable UIA AutomationId when needed. Get Text returns the real accessible text, not the normalized selector name.

For example, an existing Esra Button selector recorded with one unread message continues to identify that same Button with two, twelve, or no unread messages. A Get Text selector must still use the correct role (e.g. Text for a text label). Updating replay behavior requires rebuilding both Studio and Robot. No saved workflows need to be rewritten for legacy MSAA counter matching.

Snapshots are bounded to 1,500 nodes, depth 40 and 3.5 seconds of traversal; a partial snapshot is clearly labelled. Snapshots are session-only and can become stale after navigation. Refresh after changing the target screen. Provider calls additionally have a 15-second process timeout. Password controls expose a protected placeholder without values or an applicable selector; control values are not read during inspection. Other visible application names/text can appear in the hierarchy. This version inspects Windows accessibility trees, not browser DOM/CSS attributes, Java Access Bridge trees, or macOS applications. Run Studio at a privilege level compatible with the target application.

`node tests/ui-explorer/launch.cjs` creates an isolated Electron fixture and temporary profiles. It exercises native Click → Get Text with counts 1/2/12/0, rejects ambiguous/unrelated names and wrong roles, checks both hierarchy providers and password exclusion, and verifies Studio search/properties/edit/validate/highlight/copy/apply and dark/light layouts. It never loads or edits user workflows.
